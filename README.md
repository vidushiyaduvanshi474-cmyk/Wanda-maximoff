# Wanda-maximoff
Project Title: Chaos Magic: The Scarlet Awakening (GFG Bennett Marvel Tech Event)

Concept & Design Thinking:
For this Marvel-themed event website by the GeeksForGeeks Student Chapter, Bennett University, we broke away from traditional, predictable superhero templates. Instead, we designed an immersive, high-end experience centered around Wanda Maximoff (The Scarlet Witch).

The core design philosophy contrasts standard, orderly UI elements with raw "Chaos Magic." Visually, the site utilizes a cinematic, dark-fantasy color palette—deep crimson (#8A0303), void black (#0D0D0D), and glowing magenta accents—coupled with high-end typography (Cinzel for mystical headings and Inter for clean technical body text).

Key Interactive Features:

Dynamic Chaos CTA Button: Our registration button dynamically tracks user engagement, growing, pulsing, and shifting in real-time as users click through event titles, tracks, and schedule items.

Cinematic Hero & Hex Archive: Features an immersive countdown timer, event highlights, and a Darkhold-inspired lore archive.

Advanced Frontend Execution: Built using modern HTML5, CSS3, and JavaScript, enhanced with professional animation libraries (GSAP and Font Awesome) to ensure buttery-smooth scrolling, responsive layouts.
